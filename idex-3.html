Геолокация по IP приблизительная: она определяет страну, связанную с сетевым адресом, а не точное местоположение человека. Страница не сохраняет и не отправляет результат владельцу сайта.

Конфиденциальность

Для определения страны страница делает один запрос к стороннему сервису ipwho.is. Этот сервис получает IP-адрес, с которого пришёл запрос, и возвращает страну. Не вводи сюда личные данные.

На самой странице нет аналитики, cookies, аккаунтов, передачи результатов владельцу или сохранения истории проверок. При размещении HTML на веб-хостинге сам хостинг может вести стандартные журналы доступа.
